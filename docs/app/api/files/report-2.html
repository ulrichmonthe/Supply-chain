What it would take to get there

Nothing to build. This option changes how the existing network is used rather than what it is made of, so there are no stores to open, close or re-equip.

What this rests on

Stated up front rather than in an appendix, because a reviewer will look for it and a decision-maker deserves it.

  • 150 of 188 routes have an estimated distance rather than a measured or routed one. Every distance in the model carries the method that produced it and a confidence score; the weighted average is 0.63.
  • Seasonal access is drawn from typical conditions, not from records of routes actually closing. Worth checking with provincial staff before this is published.
